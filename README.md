# SQL Analytics Templates

A curated library of production-ready SQL queries for business analytics, reporting, and insights across sales, customers, products, and finance.

## Contents
- `sales/` — Revenue, growth, targets, and pipeline queries
- `customers/` — Segmentation, retention, churn, LTV
- `products/` — Inventory, velocity, margin analysis
- `finance/` — P&L, budget vs actuals, cost tracking
- `views/` — Reusable summary views

Compatible with PostgreSQL, BigQuery, and Snowflake (minor dialect adjustments may apply).
