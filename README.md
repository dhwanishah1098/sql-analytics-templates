# SQL Analytics Templates

Production-ready SQL for business analytics, reporting, and insights across sales, customers, products, and finance.

## Query Library

### Sales
| File | Purpose |
|------|---------|
| `revenue_summary.sql` | Monthly revenue with MoM and YoY growth |
| `pipeline_analysis.sql` | Sales pipeline stage conversion |
| `target_attainment.sql` | Rep-level target vs actual |

### Customers
| File | Purpose |
|------|---------|
| `retention_cohort.sql` | Monthly cohort retention rates |
| `ltv_ranking.sql` | Customer LTV and decile ranking |
| `churn_prediction_features.sql` | ML feature engineering for churn |

### Products
| File | Purpose |
|------|---------|
| `inventory_analysis.sql` | Stock health and turnover |

### Finance
| File | Purpose |
|------|---------|
| `budget_vs_actuals.sql` | Budget variance by department |
| `pl_summary.sql` | Monthly P&L and gross margin |

### Views
| File | Purpose |
|------|---------|
| `monthly_kpi_view.sql` | Reusable KPI summary view |

Compatible with PostgreSQL, BigQuery, and Snowflake.
